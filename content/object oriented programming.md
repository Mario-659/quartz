### encapsulation

Encapsulation is an idea of hiding implementation details when using object. Only some attributes and methods are available. We can interact with given object only though its [[API]].

We can hide and expose properties of object by using classifiers:
- private - only available inside of given class
- protected - as above + classes that inherit given class
- public - available everywhere

### abstraction

Abstraction helps to focus on essentials while ignoring less important details.

### inheritance

Inheritance enables creation of new classes based on the existing parents with option of overriding properties.

### polymorphism

Polymorphism is based on inheritance and allows objects of different classes to perform actions with the same name under different code.
